# Bambu Labs Status Bar Design

## Printer Settings

### Credentials of the printer

1. Get the Serial Number
2. Get the access code
3. Get IP address

### Configuration of the printer

1. Developer Mode:
    - Go to "Settings" on the printer display
    - Turn ON "LAN Only Mode"
    - Developer Mode Setting will appear inside the "LAN Only Mode"
    - Turn the mode ON and accept the "Terms and Conditions"
